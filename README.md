# Better Education Infoview

Better Education Infoview adds student capacity information directly to the school map overlay in the Education infoview.

## What it does

- Shows school occupancy as labels over school buildings while Education infoview is active.
- Displays current students and total capacity so you can spot crowding quickly.
- Adds color-coded capacity states (including warning colors for high utilization).

## Features

- **Live capacity labels**: Current students / total capacity shown on map.
- **Color-coded status**: Highlights crowded schools for fast visual diagnosis.
- **Customizable display**:
  - Hide empty schools
  - Scale label size
  - Adjust yellow/red warning thresholds

## Removal and compatibility

- Safe to add or remove at any time.
- Does not add persistent data to your save files.
